# 沂蒙小戏小剧官方宣传平台 PRD V0.2

## 1. 产品定位

这是“小戏小剧”的官方宣传与传播平台，而不是票务、社交或演出管理系统。

核心任务：

> 把“小戏小剧有什么、有什么好看、谁演、在哪里演、什么时候演、媒体怎么报道、过去有哪些精彩内容”持续传播出去。

## 2. 内容优先级

P0：新闻稿件 / 官方资讯  
P0：精品剧目与剧目宣传  
P0：图片、海报、视频、舞台影像  
P0：展演活动与演出预告  
P1：演员 / 主创 / 剧团介绍  
P1：直播与活动回顾  
P1：专题策划 / 主题报道  
P2：报名、互动等非核心能力

## 3. 首页信息架构

首页不再以“剧目列表”作为第一入口，而采用官方新闻门户结构：

1. 品牌头图 / 当前重点宣传
2. 最新资讯
3. 重要活动 / 展演预告
4. 精品剧目
5. 精彩视频
6. 图片 / 海报
7. 演员 / 剧团
8. 专题策划
9. 历史回顾

## 4. 一级导航

首页 / 资讯 / 剧目 / 展演 / 视频 / 我的

直播不作为一级核心导航，在有真实直播时从首页、资讯、展演或专题进入。

## 5. 资讯中心

### 列表

支持：
- 最新发布
- 重点推荐
- 展演资讯
- 剧目动态
- 媒体报道
- 文化资讯

### 详情

必须支持：
- 标题
- 来源/发布单位
- 发布时间
- 正文
- 图片
- 视频/音频
- 相关剧目
- 相关活动
- 相关新闻
- 分享

## 6. 剧目中心

剧目是宣传资产，不是后台管理对象。

剧目详情重点展示：
- 海报
- 剧目简介
- 精彩片段/完整影像
- 主创
- 演员
- 剧团
- 演出记录
- 获奖/荣誉（如有）
- 新闻报道
- 相关专题

## 7. 视频中心

以传播为目标，按：
- 精品剧目
- 演出片段
- 新闻视频
- 活动现场
- 幕后花絮

组织内容。

## 8. 展演中心

重点是“告诉公众活动发生了什么、什么时候发生、在哪里发生”。

详情支持：
- 活动主视觉
- 时间/地点
- 活动介绍
- 节目单
- 参与剧目
- 相关演员/剧团
- 新闻稿件
- 图片/视频
- 直播/回顾（如有）

## 9. H5

H5 与小程序共享内容 API，但定位更偏“传播落地页”：
- 新闻分享落地
- 剧目宣传页
- 活动宣传页
- 专题页
- 视频/图集

H5 必须支持微信内打开和分享链接直达具体内容，不要求用户先进入首页。

## 10. 内容运营原则

“资讯带流量，剧目做沉淀，视频增强传播，活动制造热点，专题建立品牌”。

后台应能控制：首页推荐、置顶、专题、焦点图、相关推荐、发布时间等，而不依赖客户端发版。

## 11. 第一版非目标

不建设：
- 在线售票
- 商业电商
- 打赏
- 粉丝社交
- 私信
- 复杂会员体系
- 演出业务管理 SaaS
