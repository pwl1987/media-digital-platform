## 1. 定位修正

### 1.1 错误定位（弃用）

```
沂蒙精神大模型 → AI 聊天 / 知识问答 / 智能助手
```

问题：缺少官方权威性、文化使命与长期价值，容易被认定为 AI 展示项目（Demo）。

### 1.2 正确定位（本 PRD 冻结）

**产品品牌：沂蒙精神数字传承平台**
副标题：以人工智能赋能沂蒙精神保护、研究与传播。

```
沂蒙精神数字传承平台
 ├─ 沂蒙精神史料库（核心资产）
 ├─ 红色文化知识库
 ├─ 人物档案
 ├─ 历史事件（时间轴）
 ├─ 文献与影像资料
 ├─ 新时代传承实践
 └─ AI 智能服务（能力模块，入口之一而非主体）
```

命名约定：

- 产品/对外品牌：**沂蒙精神数字传承平台**（导航标题、分享文案、页脚同步更名）。
- "沂蒙精神大模型"保留为**内部模型项目名**，仅指 AI 能力模块。
- 代码目录 `apps/miniapp-yimeng/` 不改名（技术标识符稳定）。

## 2. 产品使命与目标

使命：把"过去发生了什么"讲成"今天为什么还需要沂蒙精神"。

产品目标四合一：

1. **权威数字资源库**——史料、文献、影像的官方集中地。
2. **研究平台**——可检索、可引用、可溯源（每条内容带来源）。
3. **传播平台**——面向公众与青少年的红色文化多端传播。
4. **智能服务平台**——AI 问答 / 导览 / 检索 / 学习助手。

内容三维度（内容建设与审核的总框架）：

| 维度 | 内容 | 回答的问题 |
| --- | --- | --- |
| 历史维度 | 革命战争时期、根据地建设、群众支援、英烈人物 | 过去发生了什么 |
| 精神内涵 | 爱党爱军、开拓奋进、艰苦创业、无私奉献 | 沂蒙精神是什么 |
| 现实延续 | 新时代实践案例、基层故事、青少年教育、文化传播、文艺作品 | 今天为什么还需要 |

## 3. 四大核心

| 核心 | 定义 | 首期形态 |
| --- | --- | --- |
| 史料库 | 平台灵魂：文献/图片/报刊/档案/口述历史/视频/音频七类原始资料 | 分类浏览 + 检索 + 详情 |
| 知识库 | 结构化知识：精神源流、词条、时间轴、专题 | 精神源流页 + 时间轴 |
| 传播库 | 面向公众的故事、展馆、影像、分享 | 数字展馆 + 故事 + 分享闭环 |
| AI 智能服务 | 大模型赋能层：问答/导览/检索/学习助手 | 智能服务 Tab（降级为服务入口） |

## 4. 核心模块

### 4.1 精神源流（首页一级入口）

回答"什么是沂蒙精神"：精神形成 / 发展历程 / 核心内涵 / 时代价值。

### 4.2 历史记忆（核心资产，数字档案馆形态）

时间轴：1930s → 1940s → 1950s → … → 新时代。每个时间节点聚合：事件、人物、文献、图片、视频。

### 4.3 人物档案

人物卡：照片、简介、事迹、相关史料、相关视频。英烈与代表人物档案化，不用社交化呈现。

### 4.4 史料库（最核心）

```
史料 ArchiveItem
 ├ 文献  ├ 图片  ├ 报刊  ├ 档案
 └ 口述历史  ├ 视频  └ 音频
```

每条史料必备：原件/复制品图、著录信息（年代、来源、藏所）、关联实体、可引用标识。

### 4.5 影像档案

纪录片、历史影像、舞台作品、口述视频，统一 MediaAsset 管理。

### 4.6 新时代传承

实践案例、基层故事、青少年教育、文艺作品——现实延续维度的载体。

### 4.7 智能服务（AI 大模型模块）

```
智能服务
 ├ AI 问答（史料级溯源回答）
 ├ 智能导览（展馆/时间轴导览）
 ├ 资料检索（自然语言找史料）
 └ 学习助手（青少年学习任务）
```

首期仅交付 AI 问答 + 资料检索入口；导览与学习助手预留。

## 5. AI 能力规范（AI + 数字档案馆，不是聊天机器人）

回答必须呈现：

```
正文：沂蒙精神形成于……
依据：[1942 年相关文献] [某人物档案] [某历史资料]
延伸阅读：xxx
相关人物：xxx
```

- 契约映射：`sources`（史料级来源）/ `evidence`（证据条目）/ `related`（相关内容），
  字段已由 `API_CONTRACT_V0.1.md` 冻结，展示规范沿用 `UX_ACCEPTANCE_GATE` Gate D。
- Mock 回答必须标注"示例回答（未接入模型）"，不冒充真实模型能力。
- AI 不可用时有明确降级与重试；不做开放域闲聊（拒答越界问题并引导回主题）。

## 6. 内容模型影响（走 domain-types 变更流程）

| 对象 | 动作 | 说明 |
| --- | --- | --- |
| `ArchiveItem`（史料） | 新增 | `archiveType: 文献/图片/报刊/档案/口述历史/视频/音频`，著录字段（年代/来源/藏所/可引用标识），关联 Person/Event/Topic |
| `Person` | 扩展 | 人物档案：生卒、身份、事迹、关联史料/影像 |
| `Era` / 时间轴节点 | 新增 | 年代分期与节点聚合（事件+人物+史料） |
| `Topic` | 沿用 | 专题（精神源流、新时代传承专题） |
| `MediaAsset` | 沿用 | 影像档案统一载体 |

API 契约增补（待 `API_CONTRACT_V0.2` 冻结）：

```text
GET /api/v1/yimeng/archives            史料列表（archiveType/era/人物筛选 + 分页）
GET /api/v1/yimeng/archives/:id        史料详情
GET /api/v1/yimeng/timeline            时间轴（Era → 节点聚合）
GET /api/v1/yimeng/origin              精神源流
```

## 7. 平台关系

```
news-media-system（内容生产与资产管理中台）
        │  Content API
   ┌────┴─────┐
小戏小剧官方平台   沂蒙精神数字传承平台
```

- `news-media-system`：内容生产、资产管理、审核发布，两个官方平台共享同一中台，不建独立事实源。
- 本仓库（体验层）只做展示与交互；模型训练与生产 LLM Runtime 属于 `YimengSpirit-Multimodal` / `yimengjingshen`。

## 8. 非目标

- 不做：开放闲聊、UGC 社区、评论点赞、积分商城、会员体系、票务电商。
- 不做：史料数字化生产工具（属中台/兄弟仓库）。
- 第一版不做：智能导览、学习助手（仅预留入口）。
