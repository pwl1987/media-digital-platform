## 1. 定位修正

### 1.1 错误定位（弃用）

```
沂蒙精神大模型 → AI 聊天 / 知识问答 / 智能助手
```

问题：缺少官方权威性、文化使命与长期价值，容易被认定为 AI 展示项目（Demo）。

### 1.2 正确定位（本 PRD 冻结）

**产品品牌：沂蒙精神数字传承平台**
副标题：以人工智能赋能沂蒙精神保护、研究与传播。

```
沂蒙精神数字传承平台
 ├─ 沂蒙精神史料库（核心资产）
 ├─ 红色文化知识库
 ├─ 人物档案
 ├─ 历史事件（时间轴）
 ├─ 文献与影像资料
 ├─ 新时代传承实践
 └─ AI 智能服务（能力模块，入口之一而非主体）
```

命名约定：

- 产品/对外品牌：**沂蒙精神数字传承平台**（导航标题、分享文案、页脚同步更名）。
- "沂蒙精神大模型"保留为**内部模型项目名**，仅指 AI 能力模块。
- 代码目录 `apps/miniapp-yimeng/` 不改名（技术标识符稳定）。

## 2. 产品使命与目标

使命：把"过去发生了什么"讲成"今天为什么还需要沂蒙精神"。

产品目标四合一：

1. **权威数字资源库**——史料、文献、影像的官方集中地。
2. **研究平台**——可检索、可引用、可溯源（每条内容带来源）。
3. **传播平台**——面向公众与青少年的红色文化多端传播。
4. **智能服务平台**——AI 问答 / 导览 / 检索 / 学习助手。

内容三维度（内容建设与审核的总框架）：

| 维度 | 内容 | 回答的问题 |
| --- | --- | --- |
| 历史维度 | 革命战争时期、根据地建设、群众支援、英烈人物 | 过去发生了什么 |
| 精神内涵 | 爱党爱军、开拓奋进、艰苦创业、无私奉献 | 沂蒙精神是什么 |
| 现实延续 | 新时代实践案例、基层故事、青少年教育、文化传播、文艺作品 | 今天为什么还需要 |

## 3. 五层核心架构（评审冻结）

| 层 | 定义 | 首期形态 |
| --- | --- | --- |
| 史料库 | 数据资产层，平台灵魂：文献/图片/报刊/档案/口述历史/视频/音频七类原始资料 | 分类浏览 + 检索 + 详情 |
| 知识库 | 结构化知识：精神源流、词条、时间轴、专题 | 精神源流页 + 时间轴 |
| **研究服务层** | 学术研究、教育培训、宣传部门与学校使用：专家观点、研究成果、论文资料、专题研究 | **规划预留**（V1 不交付，IA 留"研究中心"扩展位） |
| 传播库 | 面向公众的故事、展馆、影像、分享 | 数字展馆 + 故事 + 分享闭环 |
| AI 智能服务 | 大模型赋能层：问答/导览/检索/学习助手 | 智能服务 Tab（降级为服务入口） |

依赖方向：史料 → 知识 → 研究服务 → 传播服务 → AI 智能服务。没有史料，AI 没有根。

### 3.1 展馆与史料的职责区分（冻结）

| | 展馆 | 史料 |
| --- | --- | --- |
| 回答 | "我如何**了解**沂蒙精神？" | "我如何**查找**真实资料？" |
| 性质 | 展示空间（偏叙事） | 数据资产（偏档案） |
| 内容 | 精神源流 / 历史长河 / 人物故事 / 时代传承 | 档案 / 文献 / 图片 / 报刊 / 音视频 / 口述资料 |
| 形态 | 沉浸长页、策展叙事 | 分类检索、著录信息、可引用 |

**展馆 = 展示空间，史料 = 数据资产，不得混用。**

## 4. 核心模块

### 4.1 精神源流（首页一级入口）

回答"什么是沂蒙精神"：精神形成 / 发展历程 / 核心内涵 / 时代价值。

### 4.2 历史记忆（核心资产，数字档案馆形态）

时间轴：1930s → 1940s → 1950s → … → 新时代。每个时间节点聚合：事件、人物、文献、图片、视频。

### 4.3 人物档案

人物卡：照片、简介、事迹、相关史料、相关视频。英烈与代表人物档案化，不用社交化呈现。

### 4.4 史料库（最核心）

```
史料 ArchiveItem
 ├ 文献  ├ 图片  ├ 报刊  ├ 档案
 └ 口述历史  ├ 视频  └ 音频
```

每条史料必备：原件/复制品图、著录信息（年代、来源、藏所）、关联实体、可引用标识。

### 4.5 影像档案

纪录片、历史影像、舞台作品、口述视频，统一 MediaAsset 管理。

### 4.6 新时代传承

实践案例、基层故事、青少年教育、文艺作品——现实延续维度的载体。

### 4.7 智能服务（AI 大模型模块）

```
智能服务
 ├ AI 问答（史料级溯源回答）
 ├ 智能导览（展馆/时间轴导览）
 ├ 资料检索（自然语言找史料）
 └ 学习助手（青少年学习任务）
```

首期仅交付 AI 问答 + 资料检索入口；导览与学习助手预留。

## 5. AI 能力规范（AI + 数字档案馆，不是聊天机器人）

回答必须呈现：

```
正文：沂蒙精神形成于……
依据：[1942 年相关文献] [某人物档案] [某历史资料]
延伸阅读：xxx
相关人物：xxx
```

- 契约映射：`sources`（史料级来源）/ `evidence`（证据条目）/ `related`（相关内容），
  字段已由 `API_CONTRACT_V0.1.md` 冻结，展示规范沿用 `UX_ACCEPTANCE_GATE` Gate D。
- Mock 回答必须标注"示例回答（未接入模型）"，不冒充真实模型能力。
- AI 不可用时有明确降级与重试；不做开放闲聊（拒答越界问题并引导回主题）。

### 5.1 来源等级（评审新增，冻结）

`sources` / `evidence` 必须显示来源等级徽章（`HeritageSourceLevel`）：

| 等级 | 定义 | 显示 |
| --- | --- | --- |
| A | 官方档案 | 深红徽章，可信度最高 |
| B | 权威出版物 | 档案蓝灰徽章 |
| C | 权威媒体 | 中性灰徽章 |
| D | 一般资料 | 浅灰徽章 + "谨慎引用"提示 |

### 5.2 时间敏感规则（评审新增，冻结）

凡涉及"现在 / 当代实践"的问题（如"现在沂蒙精神有哪些实践？"），回答必须同时包含
**历史依据 + 新时代案例**两组结构化内容（对应"现实延续"维度），不得只引用历史资料。

### 5.3 AI 生成内容标识（评审新增，冻结）

AI 回答顶部必须显示生成标识与参考资料统计：

```
本回答由沂蒙精神智能服务生成
参考资料：3 项（A 类 2 项 · B 类 1 项）
```

与人工编辑内容明确区分，杜绝"人工整理还是 AI 生成"的疑问；统计由 `sources` 数组的
`grade` 分布推导，不新增契约字段。

## 6. 内容模型影响（评审升级：HeritageResource 体系，走 domain-types 变更流程）

```
HeritageResource（顶层抽象）
 ├─ ArchiveItem     七类史料（文献/图片/报刊/档案/口述历史/视频/音频）
 ├─ Story           新时代故事 / 基层实践 / 教育案例（现实延续，不归入 Archive）
 ├─ Person          人物档案（生卒、身份、事迹、关联史料/影像）
 ├─ MediaAsset      影像档案（沿用既有对象）
 └─ TimelineEvent   时间轴事件（年代、地点、聚合人物/史料）

SourceReference     来源引用（来源名、 locator、等级 A–D）
Evidence            证据条目（label、title、指向 HeritageResource）
```

顶层共用字段：`sourceLevel`（A–D 等级）、`sourceReferences`、`era`（年代分期）、
`topics`、`status`（发布状态）。引用关系（citation graph）是 Y2 交付物。

> 命名说明：评审将原 `ArchiveItem` 顶层方案升级为 `HeritageResource`——新时代传承案例
> 不属于"档案"，用 Story 承载，避免领域模型错位。

API 契约增补（待 `API_CONTRACT_V0.2` 冻结）：

```text
GET /api/v1/yimeng/archives            史料列表（archiveType/era/人物筛选 + 分页）
GET /api/v1/yimeng/archives/:id        史料详情
GET /api/v1/yimeng/timeline            时间轴（Era → TimelineEvent 聚合）
GET /api/v1/yimeng/origin              精神源流
```

## 7. 平台关系

```
news-media-system（内容生产与资产管理中台）
        │  Content API
   ┌────┴─────┐
小戏小剧官方平台   沂蒙精神数字传承平台
```

- `news-media-system`：内容生产、资产管理、审核发布，两个官方平台共享同一中台，不建独立事实源。
- 沂蒙平台在共享中台之上**自建 Heritage Knowledge Layer**（史料著录、知识结构、引用关系）——
  领域知识不完全依赖新闻系统，中台管内容生产与资产，知识层管领域结构。
- 本仓库（体验层）只做展示与交互；模型训练与生产 LLM Runtime 属于 `YimengSpirit-Multimodal` / `yimengjingshen`。

## 8. 非目标

- 不做：开放闲聊、UGC 社区、评论点赞、积分商城、会员体系、票务电商。
- 不做：史料数字化生产工具（属中台/兄弟仓库）。
- 第一版不做：智能导览、学习助手（仅预留入口）。
