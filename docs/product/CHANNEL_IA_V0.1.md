# 多渠道信息架构 V0.1

## 小戏小剧官方宣传平台

### 微信小程序
首页 / 资讯 / 剧目 / 视频 / 我的

- 首页：重点宣传、最新资讯、重点展演、精品剧目、精彩视频、专题
- 资讯：最新发布、重点推荐、展演资讯、剧目动态、媒体报道、文化资讯
- 剧目：分类、作品详情、主创、演员、剧团、演出记录、新闻/视频关联
- 视频：精品剧目、演出片段、新闻视频、活动现场、幕后花絮
- 我的：收藏、历史、设置/协议

### H5
以传播落地为核心：
- /news/:id
- /work/:id
- /event/:id
- /video/:id
- /topic/:id

H5 默认支持微信内分享直达，不要求先进入首页。

### PC Web
正式门户，采用双层导航：
- 主导航：首页、资讯、剧目、视频、展演、专题
- 次导航：演员、剧团、数字档案、关于平台

PC 首页信息密度高于小程序；详情页允许从新闻进入剧目/活动/视频，从剧目进入相关新闻/视频/演出。

## 沂蒙精神

### 微信小程序
首页 / 知识 / AI问答 / 展馆 / 我的

### PC Web
首页 / AI智能问答 / 知识库 / 人物 / 故事 / 历史 / 数字展馆 / 专题

### 移动 App
统一 App 壳采用首页 + 频道 + 内容详情 + AI + 我的。频道可承载“沂蒙精神”和“小戏小剧”两个专区，后续可扩展其他文化专题。

## 统一页面模板

所有渠道共享以下业务语义：

- Feed / 首页内容编排
- Content Detail / 内容详情
- Person Detail / 人物详情
- Organization Detail / 机构详情
- Work Detail / 作品详情
- Event Detail / 活动详情
- Media Detail / 视频/音频详情
- Topic Detail / 专题详情
- Search / 搜索

视觉、信息密度、交互手势可因渠道不同而不同，但不能改变对象身份与关系语义。
