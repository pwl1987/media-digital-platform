# 沂蒙小戏小剧官方资讯传播链 V0.1

## 目标

把“官方新闻稿件”作为小戏小剧宣传平台的核心传播单元，做到一次发布、多端消费、关联内容贯通、可直接分享。

## 标准链路

```text
官方编辑发布 News
  ↓
Content API
  ↓
小程序 / H5 / PC / App
  ↓
News Detail
  ├─ 官方来源
  ├─ 发布时间
  ├─ 正文/媒体
  ├─ 相关剧目
  ├─ 相关活动
  ├─ 相关视频
  └─ 相关新闻/专题
```

## 产品规则

1. `News` 是一等内容对象，不以页面作为数据身份。
2. 只有已发布内容进入公众端。
3. 官方稿件显示来源等级与发布单位。
4. 转载内容必须保留转载/媒体来源信息，不冒充官方原创。
5. 详情页必须允许继续跳转到关联内容。
6. 微信小程序支持分享直达新闻详情。
7. H5 必须支持 `/news/:id` 直达。
8. PC Web 使用同一新闻 ID 和语义，不复制另一套新闻数据。
9. 下架/撤稿以后，所有渠道应一致返回不可用状态，而不是保留旧内容。
10. 首页推荐、置顶、焦点图属于运营编排，不进入 News 本体。
