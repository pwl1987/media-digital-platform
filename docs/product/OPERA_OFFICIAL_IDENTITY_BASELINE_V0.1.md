# 沂蒙小戏小剧官方平台身份基线 V0.1

## 1. 官方属性

本产品统一定位为：**沂蒙小戏小剧官方宣传与传播平台**。

“官方”是产品身份，而不是一个页面标签。所有渠道（微信小程序、H5、PC Web、移动 App）都遵循同一官方内容治理与发布体系。

## 2. 产品目标

1. 权威发布小戏小剧相关新闻、公告、展演资讯与专题报道。
2. 集中展示精品剧目、演员、剧团及舞台影像。
3. 扩大优秀小戏小剧作品的公众触达与二次传播。
4. 为媒体、公众和活动参与者提供统一的信息入口。
5. 通过内容资产沉淀形成长期数字文化品牌。

## 3. 内容信任层级

P0：官方发布 / 主办方发布的新闻与公告  
P0：官方剧目资料、活动资料、视频与图片  
P1：经审核的媒体报道与转载内容  
P1：专题策划与历史资料  
P2：用户侧互动内容（第一版不作为核心内容源）

所有内容应具备来源、发布时间、发布状态和可追溯关系；需要时标明“资料来源/转载来源”。

## 4. 渠道原则

- 小程序：高频传播与微信分享入口。
- H5：新闻、剧目、活动、专题的分享落地页。
- PC Web：完整官方门户、专题展示与内容检索。
- Mobile App：统一移动端内容消费与通知入口。

四端共享 Content API，不允许各端建立独立事实源。

## 5. 首页原则

官方身份必须在首屏可感知：品牌名称、官方标识/说明、重点宣传内容、最新资讯必须形成清晰层级。

小戏小剧宣传首页的核心排序：

> 重点宣传 → 最新资讯 → 展演动态 → 精品剧目 → 精彩视频 → 专题

## 6. 明确不做

第一版不将票务、电商、打赏、粉丝社交、私信、复杂会员及演出业务管理作为产品核心。
