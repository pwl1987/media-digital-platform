# 沂蒙小戏小剧官方平台：内容传播闭环 V0.1

## 目标

以“官方资讯”为流量入口，以剧目为长期内容资产，以视频增强传播，以展演形成热点，以专题沉淀品牌。

## 三条核心对象链

### News

News → Work / Event / Person / MediaAsset / Topic

### Work

Work → Artist / Organization / Performance / MediaAsset / News / Topic

### Event

Event → Performance / Work / News / MediaAsset / Topic

## 渠道传播

同一个稳定内容 ID 在微信小程序、H5、PC Web、Mobile App 使用同一业务语义。

- 小程序：高频消费与微信分享
- H5：社交传播直达落地页
- PC：官方门户、专题与深度检索
- App：长期订阅、通知、收藏和视频消费

## 内容详情最低要求

官方新闻：来源、发布日期、正文、媒体附件、相关剧目/活动/视频、分享。

剧目：海报、简介、主创、演员、剧团、演出记录、舞台影像、相关新闻、专题。

展演：主视觉、时间、地点、节目/剧目、相关新闻、图片/视频、直播或回顾。

视频：封面、标题、分类、播放状态、来源、关联剧目/活动/新闻、分享。

## 发布原则

客户端只消费已发布内容。内容撤稿或下架后，各渠道都必须停止继续展示，并保留用户已经打开的详情页的明确下架/不可用状态，而不能继续依赖旧缓存作为事实源。
