# 小戏小剧宣传定位 V0.1

## 产品判断

“沂蒙小戏小剧”第一阶段的核心任务是文化宣传与传播，不是票务系统、社交社区或商业化平台。

## 核心传播链

品牌露出 → 精品作品 → 舞台影像 → 演员/剧团 → 展演资讯 → 直播/回顾 → 分享传播

## 首页优先级

1. 主视觉与品牌主张
2. 精品剧目与代表作品
3. 近期展演/重要活动
4. 直播与精彩回顾
5. 演员/剧团故事
6. 文化专题与平台介绍

## 第一阶段不作为核心

- 在线售票
- 打赏
- 粉丝/私信
- 用户社区
- 复杂报名流程
- 商业化变现

活动报名可以作为外链/轻量入口保留，但不应抢占内容宣传主路径。

## 内容运营原则

首页所有宣传位应由后端 Feed/Collection 控制，前端只负责展示；避免把宣传内容写死在小程序代码中。

作品详情的目标是“让用户认识作品”，而不是只看一个视频。应优先展示作品简介、主创、演员、剧团、演出记录与相关影像。

## 传播指标

第一阶段重点观察：

- 首页进入率
- 精品剧目点击率
- 作品详情到视频播放转化
- 展演资讯点击率
- 分享次数
- 直播进入率

用户登录不是达成上述目标的前置条件。
