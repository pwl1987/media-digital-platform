## 5. 关键页面规范

职责总区分（冻结）：**展馆 = 展示空间**（回答"我如何了解"，沉浸叙事，深色长页）；
**史料 = 数据资产**（回答"我如何查找真实资料"，档案工作台，浅色著录风格）。两类页面不得混用视觉范式。

### 5.1 数字展馆（museum）

三厅结构：精神源流厅（内涵叙事）→ 历史记忆厅（时间轴沉浸）→ 新时代厅（现实延续）。
每厅为可横向分节的沉浸长页，出口统一指向人物/史料/影像实体页。

### 5.2 历史记忆（memory）

垂直时间轴：年代锚点（1930s…新时代）→ 节点卡（事件标题 + 时间 + 关联人物/史料缩略）。
节点点击进入聚合视图：事件 + 人物 + 文献 + 图片 + 视频。

### 5.3 史料库（archive）

顶部七类分类 tab + 年代/人物筛选；列表卡（缩略 + 标题 + 著录摘要 + 类型徽标）；
支持关键词检索与"自然语言找史料"入口（跳转智能服务）。

### 5.4 史料详情（archive-detail）

按 `archiveType` 渲染：文献（原文图 + 转录文）、口述历史（音视频 + 文字稿）、
图片/报刊/档案（大图 + 著录）、视频/音频（播放器）。
著录信息固定区：年代、来源、藏所、可引用标识（Gate B：来源可理解）。

### 5.5 人物档案（person-detail）

庄重人像 + 名条 + 生卒/身份 + 事迹长文 + 相关史料列表 + 相关视频。
禁止社交化元素（关注、粉丝、评论）。

### 5.6 智能服务（ai）

沿用会话流与建议问题；回答区必须呈现 依据（sources）/ 证据（evidence）/ 相关内容（related）
三段（视觉规范见 `YIMENG_UI_VISUAL_BASELINE` §4.4，V0.2 修订后执行）；
新增"资料检索"快捷入口：自然语言 → 史料结果列表。

## 6. 核心闭环（更新）

```
主闭环：首页 → 精神源流 → 历史记忆时间轴 → 人物档案 → 史料详情 → 相关影像
AI 闭环：任意内容详情 → 带上下文进入 AI 问答 → 溯源回答（sources 可回跳史料详情）
传播闭环：史料/人物/故事 → 微信分享卡片 → H5 落地（V1.1）→ 回流小程序
```

对应 `UX_ACCEPTANCE_GATE_V0.1` Gate A：详情可继续进入相关实体、AI 可带上下文进入、搜索可进入统一详情。
