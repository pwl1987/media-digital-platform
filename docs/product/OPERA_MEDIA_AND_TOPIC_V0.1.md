# 沂蒙小戏小剧官方平台：视频、图片与专题 V0.1

## 视频中心

视频是新闻传播后的重要二次传播载体，不独立于内容体系。

分类：
- 精品剧目
- 演出片段
- 新闻视频
- 活动现场
- 幕后花絮

每条视频至少关联：来源、所属剧目/活动/新闻（如有）、封面、媒体地址、时长、发布状态。

## 图片 / 图集

图片不是装饰资源，而是新闻、剧目、活动和专题的传播资产。

推荐场景：
- 新闻正文图
- 剧目海报
- 演出现场图
- 活动主视觉
- 幕后花絮
- 专题图集

## 专题

专题用于阶段性传播重点，不应与普通新闻栏目混用。

专题结构建议：

主题头图 → 导语 → 重点新闻 → 关联剧目 → 精彩视频 → 相关活动 → 人物/剧团 → 图集 → 往期内容

## 渠道要求

小程序突出快速浏览和分享；H5 突出单篇传播和专题落地；PC 突出专题深度浏览和检索；App 突出订阅和长期消费。

## 运营原则

专题与视频位均由后台发布策略控制，客户端不得把某一条内容永久写死为“重点”。
