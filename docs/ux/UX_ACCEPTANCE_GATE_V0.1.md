# UX / 页面实现验收门禁 V0.1

## Gate A：信息架构

- [ ] 一级导航与 PRD 一致
- [ ] 页面职责单一且可描述
- [ ] 详情页可继续进入相关实体/内容
- [ ] 搜索结果可进入统一详情
- [ ] AI 可以从内容详情带上下文进入

## Gate B：内容体验

- [ ] 所有内容有明确标题、摘要或身份信息
- [ ] 媒体内容有加载、播放失败、无资源状态
- [ ] 下线/不存在内容不会出现死链空白页
- [ ] 来源/证据信息可以被用户理解
- [ ] 分享目标可恢复到原内容

## Gate C：状态体验

所有异步页面必须验证：

1. 首次加载
2. 列表为空
3. 网络失败
4. 重试
5. 内容不存在
6. 下拉刷新/重新进入

## Gate D：AI 体验

- [ ] 新建会话
- [ ] 多轮上下文
- [ ] 流式/渐进式回答的展示接口已预留
- [ ] 回答来源/证据与正文视觉区分
- [ ] AI 不可用时有明确降级
- [ ] 不把 Mock 回答标记为真实模型能力

## Gate E：媒体体验

- [ ] 视频首帧/封面
- [ ] 播放中
- [ ] 缓冲中
- [ ] 播放失败
- [ ] 无播放地址
- [ ] 网络切换后的恢复策略

## Gate F：适老化

- [ ] 核心文字可读
- [ ] 关键按钮有足够点击区域
- [ ] 信息不只由颜色表达
- [ ] 视频/音频内容提供必要文字辅助

## Gate G：微信运行要求

- [ ] 页面路径存在且与 app.json 一致
- [ ] tabBar 页面只能使用 switchTab
- [ ] 非 tab 页面使用 navigateTo / redirectTo
- [ ] request 不散落在页面代码
- [ ] API base URL 仅通过配置/Client 管理
- [ ] 正式环境不允许 Mock 数据默认启用
- [ ] 真机验证网络、媒体、分享、登录相关能力

## Gate H：发布前

- [ ] 隐私政策与用户协议
- [ ] 小程序类目与功能一致
- [ ] 业务域名 / request 合法域名 / upload 合法域名等环境配置
- [ ] 内容审核链路
- [ ] 下线/撤稿能力
- [ ] 错误监控与关键行为日志
- [ ] 版本回滚方案

## 通过标准

页面不是“能打开”即算完成。必须同时满足：

`IA 正确 + 数据边界正确 + 状态完整 + 交互可用 + API 解耦 + 微信运行验证通过`。
