## 1. 定位与气质

**「庄重的红色文化纪念与教育空间」**：纪念性、教育性、沉浸叙事。

与小戏小剧门户的区别：门户重"传播与丰富"，沂蒙精神重"庄重与深度"——
大留白、史料质感、长文阅读、时间叙事。视觉更素，红更少而更重。

关键词：庄重 / 纪念 / 教育 / 叙事 / 沉浸。

负面清单：娱乐化、游戏化、社区化、促销感；同样禁止 SaaS 风。

## 2. 色彩

沿用同一套 token（见 `OPERA_UI_VISUAL_BASELINE_V0.1.md` §2），配比不同：

| 角色 | 色值 | 占比 |
| --- | --- | --- |
| 底：宣纸白 `--ym-paper` / 卡片白 | `#F7F3EA` / `#FFFFFF` | ~75% |
| 文：墨黑 `--ym-ink` 与正文灰阶 | `#1F1F1F` 系列 | ~20% |
| 点睛：沂蒙红 `--ym-red-700` | `#8B1E24` | ~5%，仪式性使用 |
| 荣誉：金 `--ym-gold-500` | `#C9A227` | 仅勋章/荣誉/年代装饰 |

红色仪式性用法：语录左条、人物名条、时间线节点、AI 回答引用块、关键按钮。
禁止大面积红底（主视觉深色遮罩除外，用 `red-900 → ink` 渐变）。

## 3. 字体

- 同字体栈；serif 占比高于小戏小剧：语录、人物名、年代、展项标题均用 serif。
- 长文（故事/历史正文）行距 1.75，正文 28rpx 起步；**适老化档**：设置内提供 +2rpx 字号档（Gate F，中老年为主要受众之一）。

## 4. 组件

### 4.1 QuoteBlock 语录块

宣纸底 + 左 6rpx 红条 + serif 引文 + 出处 caption。用于红嫂语录、精神表述。

### 4.2 PersonCard 人物卡

庄重人像（3:4，墨色微降饱和处理）+ 底部红色名条（白字姓名）+ 身份/事迹 caption。
不使用圆形头像 + 社交昵称式布局。

### 4.3 Timeline 历史时间线

垂直主线 `--ym-line` + 红色节点 + serif 年代 + 事件卡。用于精神形成与发展脉络、展馆时间轴。

### 4.4 SourcesBlock AI 引用三段（Gate D 核心组件）

AI 回答的 `sources / evidence / related` 三个契约字段必须可视化且与正文**视觉区分**：

```
回答正文（白卡）
├─ 参考资料 sources   ：red-50 底列表，行内来源名 + 类型 tag
├─ 证据 evidence       ：宣纸底 + 红左条，标注"平台知识条目"
└─ 相关内容 related    ：横滑内容卡（人物/故事/专题）
```

- Mock 回答必须显式标注"示例回答（未接入模型）"，不得冒充真实模型能力。
- AI 不可用时有明确降级提示与重试（Gate D）。

### 4.5 ExhibitCard 展项卡

数字展馆用：展项图 4:3 + serif 展项名 + 馆区 caption，支持分区（展厅）分组。

## 5. 页面要点

- **首页**：精神内核主视觉（深色渐变 + serif 主题表述）→ 精选故事 → 人物 → 历史脉络（Timeline 摘要）→ 展馆入口 → AI 问答入口。
- **知识**：词条 + 时间线双形态；词条用引言块 + 长文排版。
- **AI 问答**：会话消息流 + 建议问题（chips，灰描边）+ SourcesBlock；输入区固定底部，主按钮红。
- **展馆**：展厅分节横滑 + 展项卡网格。
- **我的**：浏览历史与收藏用统一内容卡，无社交元素。

## 6. 适老化（Gate F，权重高于小戏小剧）

- 关键操作点击区域 ≥ 88rpx。
- 信息不只由颜色表达（双通道规则同小戏小剧基线 §2.3）。
- 视频/音频内容配文字摘要或字幕说明。

## 7. 验收

- [ ] 庄重气质：红面积 ≤5%，无娱乐化元素
- [ ] 语录/人物/时间线使用 serif 仪式性排版
- [ ] AI 回答 sources/evidence/related 三段可视化且与正文区分（Gate D）
- [ ] Mock 回答带"示例回答"标识
- [ ] 适老化档位与点击区域达标
- [ ] 全部色值走 token，无硬编码
