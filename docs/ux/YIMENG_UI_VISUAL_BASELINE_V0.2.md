> 状态：**Design Freeze V0.2 候选**。取代 `YIMENG_UI_VISUAL_BASELINE_V0.1.md`
> （产品重定位为"数字传承平台"后视觉方向调整）。配套 `YIMENG_HERITAGE_PRD_V1.0.md`
> （评审冻结版）与 `docs/domain/HERITAGE_DOMAIN_MODEL_V0.2.md`。

## 1. 视觉方向：数字纪念馆

关键词：庄重 / 历史 / 厚重 / 纪念 / 权威 / 档案感。

**是"数字纪念馆"，不是"党建宣传页"**。负面清单（禁止）：

- 大红横幅、口号刷屏、整屏红底金字
- 党徽式装饰、宣传海报排版
- 亮色渐变、喜庆氛围、营销感
- 与小戏小剧门户（红金宣纸）同质化——沂蒙更沉、更素、更档案

## 2. 色彩体系（`--ymh-*` 前缀，进 design-system tokens）

### 2.1 品牌与中性

| Token | 值 | 用途 |
| --- | --- | --- |
| `--ymh-red-900` | `#47100F` | 展馆沉浸区渐变深端 |
| `--ymh-red-800` | `#6E1418` | **深红·主色**：仪式性强调、A 级徽章、关键按钮 |
| `--ymh-red-500` | `#8C2A31` | 次强调、hover |
| `--ymh-paper` | `#F2ECDF` | **旧纸·页面底色** |
| `--ymh-paper-deep` | `#E9E0CC` | 分区底、卡片描边、引言块 |
| `--ymh-slate-700` | `#43525F` | 著录标题、研究性 UI 强调 |
| `--ymh-slate-600` | `#5B6B7A` | **档案蓝灰**：著录信息、时间轴辅助、B 级徽章 |
| `--ymh-slate-300` | `#A7B3BE` | 禁用、辅助线 |
| `--ymh-slate-100` | `#E3E8EC` | 蓝灰浅底（筛选器、著录表格行） |
| `--ymh-stone` | `#8A8578` | **石材灰**：分割线、底纹、时间轴线 |
| `--ymh-ink` / `--ymh-text` | `#1F1F1F` / `#3D3D3D` | 标题 / 正文（沿用） |
| `--ymh-gold-500` | `#C9A227` | **仅勋章/荣誉**，禁止用于装饰线与导航 |

### 2.2 配比与规则

- 旧纸白 ≈70% / 墨+蓝灰 ≈22% / 深红 ≈6% / 金 ≤2%。深红比小戏小剧更少、更重。
- 正文对比度 ≥4.5:1；深色沉浸区文字用旧纸白，禁止中灰字压深红底。
- 状态语义沿用 OPERA 基线 §2.3 的字段映射与"颜色+文字"双通道规则。

## 3. 影像双色调叙事（本基线核心特色）

| 内容年代 | 处理 | 视觉 |
| --- | --- | --- |
| 历史影像 / 史料图 | 黑白或深褐双色调（grayscale + 微 sepia） | 单色 |
| 新时代内容（Story / 实践案例） | 原彩 | 彩色 |
| 人物档案照片 | 统一黑白 + 石材灰衬底 | 单色 |

形成 **"历史 = 单色，当下 = 彩色"** 的叙事语言：用户在时间轴、AI 回答、展馆中
凭色彩即可区分历史依据与新时代案例，直接支撑 PRD §5.2 时间敏感规则。

## 4. 材质与两种页面范式

- 石材/旧纸纹理仅用于**展馆沉浸区背景与专题横幅**，噪点 ≤4%，不伤文字对比度。
- 两种页面范式（冻结，不得混用）：

| | 展馆（展示空间） | 史料（数据资产） |
| --- | --- | --- |
| 底色 | 深色沉浸（red-900→ink 渐变 + 石材纹理） | 浅色档案工作台（旧纸白 + slate-100 表格行） |
| 排版 | 策展长页叙事、serif 大标题 | 检索框突出、著录表格化、蓝灰筛选器 |
| 交互 | 浏览、驻留 | 检索、筛选、引用 |

## 5. 字体排印

沿用 V0.1 字体栈与字号阶梯；调整：

- serif 比例进一步提高：年代数字（如 **1940s**）用衬线大字做时间锚点（EraAnchor）。
- 著录信息（年代、编号、页码）使用 tabular 等宽数字对齐。
- 适老化：字号 +2rpx 档、点击区 ≥88rpx、双通道表达——全部沿用 V0.1 §6，权重高于小戏小剧。

## 6. 组件规范

沿用 V0.1：QuoteBlock / PersonCard / Timeline / ExhibitCard / Empty / Loading / Error。
调整与新增：

### 6.1 SourceGradeBadge 来源等级徽章（PRD §5.1）

| 等级 | 样式 |
| --- | --- |
| A 官方档案 | 深红底旧纸白字 |
| B 权威出版物 | 档案蓝灰底白字 |
| C 媒体报道 | 中性灰底白字 |
| D 一般资料 | slate-100 底灰字 + 「谨慎引用」提示 |

AI 回答的 sources/evidence 与史料著录区必带。

### 6.2 ArchiveCard 史料卡

缩略图（按 §3 双色调规则）+ 类型徽标（七类）+ 标题 + 著录行（年代 · 来源 · 等级徽章）。

### 6.3 著录信息区（史料详情固定区）

表格化：年代 / 来源 / 藏所 / 可引用标识 / 来源等级 / 原件-复制品。对应领域模型著录字段。

### 6.4 CitationList 引用关系

史料详情底部：「本史料引用」「被引用」两组列表，Y2 交付。

### 6.5 SourcesBlock 升级（AI 回答）

在 V0.1 三段（sources/evidence/related）基础上：

- 回答顶部**AI 生成标识条**（slate-100 底 + 蓝灰字）："本回答由沂蒙精神智能服务生成 ·
  参考资料 N 项（A 类 x · B 类 y …）"——统计由 sources 的 grade 分布推导（PRD §5.3）；
- 每条 source 附 SourceGradeBadge；
- 时间敏感问题（PRD §5.2）时，正文分为 **历史依据**（单色缩略）与 **新时代案例**（彩色缩略）两组。

### 6.6 EraAnchor 年代锚点

时间轴年代节点：衬线大字年代 + 石材灰横线 + 深红节点。

## 7. 关键页面视觉要点

- **首页**：深色主视觉（旧纸白 serif 标题 + red-900 底 + 微石材纹理）→ 其余分区浅色旧纸底；AI 入口为末位弱化卡片。
- **展馆**：三厅沉浸深色长页（见 §4 范式表）。
- **史料库**：浅色工作台——顶部检索框（显著）+ 七类分类 tab + 蓝灰筛选器 + ArchiveCard 列表。
- **史料详情**：大图 + 著录表格区 + 正文/文字稿 + 引用关系。
- **智能服务（AI）**：会话流 + 建议问题 + SourcesBlock（等级徽章 + 时间分组）；Mock 标注沿用。

## 8. Token 落地

`--ymh-*` 与小戏小剧 `--ym-*` 并列进入 `packages/design-system` tokens
（`tokens.json` 源 → `tokens.wxss` / `tokens.css`，生成链同 OPERA 基线 §12）。
两套 token 独立成组，共享生成机制；禁止硬编码色值。

## 9. 验收检查单

- [ ] 数字纪念馆气质：无党建宣传页元素、无口号刷屏
