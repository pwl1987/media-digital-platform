# 沂蒙精神数字传承平台架构基线 V0.1

> 一页纸基线：领导汇报与开发依据的统一入口。细节见文末文档索引。
> 状态：**冻结**（Phase Y0 产出，评审通过）。

## 1. 定位

**沂蒙精神数字传承平台**——以人工智能赋能沂蒙精神保护、研究与传播。
"沂蒙精神大模型"为内部模型项目名，仅指 AI 能力模块。

## 2. 目标

**保护、研究、传播、传承**：

1. 保护——建设官方权威的沂蒙精神数字资源库（史料库）。
2. 研究——可检索、可引用、可溯源的知识体系。
3. 传播——面向公众与青少年的多端红色文化传播。
4. 传承——以新时代实践回答"今天为什么还需要沂蒙精神"。

## 3. 五层架构

```
史料库   （数据资产：档案/文献/图片/报刊/口述/音视频）
   ↓
知识库   （结构化：精神源流/词条/时间轴/专题）
   ↓
研究服务 （规划预留：专家观点/研究成果/论文/专题研究）
   ↓
传播库   （数字展馆/故事/影像/分享）
   ↓
AI 智能服务（问答/导览/检索/学习助手——能力层，非主体）
```

展馆 = 展示空间（"我如何了解"）；史料 = 数据资产（"我如何查找真实资料"）。

## 4. 平台架构

```
                news-media-system（内容生产/媒资/新闻管理中台）
                          │ Content API
          ┌───────────────┴───────────────┐
   小戏小剧官方平台                 沂蒙精神数字传承平台
   （传播层）                      （知识传承层）
                                         │
                              Heritage Knowledge Layer
                              （史料著录/知识结构/引用关系——平台核心资产）
```

## 5. 技术原则

1. **AI 不生产历史，只辅助理解**——史料先行，知识次之，AI 最后；顺序不可颠倒。
2. 领域模型唯一来源：`packages/domain-types`（HeritageResource 体系）。
3. 契约先行：接口以 `API_CONTRACT` 当前冻结版为准。
4. 来源等级 A–D 全链路可见；AI 回答必须带生成标识与参考资料统计。
5. 视觉语言：历史单色 / 当代彩色（双色调叙事）；数字纪念馆风，非党建宣传页。
