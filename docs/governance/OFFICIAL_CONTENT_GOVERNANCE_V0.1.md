# 官方内容治理规范 V0.1

## 1. 目标

建立“小戏小剧官方平台”四端统一的内容信任、审核、发布、撤回与追溯规则。

## 2. 来源层级

- OFFICIAL：官方发布/官方授权资料
- ORGANIZER：主办/承办单位发布
- MEDIA_REPOST：经审核的媒体报道或转载
- ARCHIVE：历史资料/档案
- USER：用户内容；第一版不作为核心内容源

## 3. 内容生命周期

```text
DRAFT → REVIEWING → APPROVED → SCHEDULED → PUBLISHED
                                      │
                                      └→ UNPUBLISHED / RETRACTED
```

客户端只消费可公开发布状态；撤稿、下架、定时发布由业务控制面决定。

## 4. 必备字段

每条公开内容至少具备：

- stable id
- type
- title
- source
- published_at
- status
- canonical URL/locator
- related content where applicable

转载内容必须标明来源，不得伪装为官方原创。

## 5. 官方标识

首屏或详情头部应可识别“官方资讯/官方发布”等信任层级。不同来源使用明确标签：官方、主办方、媒体报道、历史资料。

## 6. 撤稿与更正

内容下架不删除稳定身份；客户端显示“内容已下架”或“内容已撤回”状态，不展示缓存的旧正文作为正常内容。

发生事实更正时，使用版本化内容或更正说明，保留审计关系。

## 7. 运营控制

首页焦点、置顶、推荐、专题归属、关联内容、发布时间均由后台控制，不通过客户端发版实现。

## 8. 审计要求

发布、审核、撤回、来源变更和关键关联变更应保留操作记录，供后台审计和问题追溯使用。
