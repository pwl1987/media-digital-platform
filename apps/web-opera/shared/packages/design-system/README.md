# Design System

多渠道体验层共享的 Design System 边界。

## Shared semantics
- color / typography / spacing / radius / elevation tokens
- ContentCard / NewsCard / MediaCard / EventCard
- Empty / Error / Loading / Offline states
- Official source badge / publication timestamp
- Share / favorite / related-content affordances

各渠道可以有独立视觉风格，但不能改变核心交互语义和内容信任表达。
