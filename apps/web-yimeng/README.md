# 沂蒙精神 PC Web\n\n官方知识与智能传播门户，同时承担阶段性研发成果演示入口。\n\n## 当前实现\n\n`feature/yimeng` 已补齐第一版可独立运行的 PC 演示门户：\n\n- 项目阶段成果总览\n- 红色文化数字档案接入位\n- 智能服务接入位\n- 阶段成果核验清单\n- 响应式 PC / 移动浏览器布局\n\n## 运行方式\n\n该版本为纯静态前端，无构建依赖。可由任意静态 HTTP Server 托管 `apps/web-yimeng/`。\n\n默认不内置或伪造正式史料、资源数量和模型回答。需要联调真实数据/模型服务时，在页面加载前设置 `window.YIMENG_DEMO_CONFIG` 的 `apiBase`。\n\n接口遵循 `docs/api/API_CONTRACT_V0.2.md`，主要使用：\n\n- `GET /api/v1/yimeng/archives`\n- `POST /api/v1/yimeng/ai/chat`\n\n## 证据用途\n\n本门户可作为项目阶段成果现场演示和运行截图来源。截图应来自真实运行页面；正式数据规模、资源授权、审核结论和投资金额仍以项目正式台账及原始凭证为准。\n\n## 后续\n\n1. 接入经审核确认的正式史料数据；\n2. 接入 `YimengSpirit-Multimodal` / 智能服务部署环境；\n3. 增加人物、故事、时间轴和来源回链的 PC 详情页；\n4. 增加截图基线与自动化浏览器验收。
